# EcoSentinel Agent Instructions

This is the project-level instruction file for agents working in this repository.
It applies to all research, data-acquisition, audit and coding tasks unless a more
specific instruction file in a subdirectory adds stricter requirements.

## Mandatory Research and Execution Standards (Permanent)

### A. Extensive search requirement

- Conduct an extensive, systematic search appropriate to the research question.
- Prioritise primary sources, original datasets, official metadata, technical
  documentation, original scientific publications and authoritative institutional
  sources.
- Search existing project evidence and previous research before repeating work.
- Follow relevant references and citation trails rather than stopping at the first
  useful result.
- Investigate conflicting evidence and report disagreements.
- Do not treat search-engine snippets, abstracts or secondary summaries as
  substitutes for primary evidence when primary sources are accessible.

### B. Strict search-depth requirement

For every substantial research task:

- Define the relevant source categories before searching.
- Search each relevant category systematically.
- Inspect complete relevant documents, metadata records and datasets where
  accessible, not merely titles or abstracts.
- Follow relevant linked resources, supplementary files, data dictionaries and
  methodological references.
- Check publication dates, dataset versions, revisions, licences and provenance.
- Distinguish sources actually inspected from sources merely identified.
- Maintain a search log recording queries, sources inspected, inaccessible sources,
  exclusions and reasons for stopping.
- Provide evidence supporting every material conclusion.
- State unresolved questions and evidence gaps explicitly.

A search is not complete merely because several sources have been found. It is
complete only when the defined search scope has been covered or remaining access
limitations have been documented.

### C. No context-window or token-budget shortcuts

- Never reduce the requested research scope merely to conserve context-window
  capacity, tokens or computational resources.
- Never silently omit checks, source categories, deliverables, validation steps or
  required analysis.
- Never substitute a superficial summary for a requested detailed investigation.
- Never claim that a task is complete when only a subset has been completed.
- Split large tasks into sequential, documented phases where necessary.
- Persist intermediate findings, source references, decisions and outstanding work
  to files.
- Maintain a durable handover so work can continue across sessions without losing
  evidence.
- If context capacity becomes a genuine limitation, stop at a safe checkpoint,
  document precisely what remains and request continuation. Do not manufacture a
  completion verdict.
- Resource constraints must be reported transparently, not used as permission to cut
  corners.

### D. Evidence and scientific integrity

- Separate verified observations, source-reported claims, interpretations and
  hypotheses.
- Never invent measurements, citations, source contents or completed checks.
- Never infer missing information without explicitly identifying the inference.
- Preserve negative findings and contradictory evidence.
- Maintain reproducibility and provenance.
- Do not weaken project governance to make progress appear faster.
