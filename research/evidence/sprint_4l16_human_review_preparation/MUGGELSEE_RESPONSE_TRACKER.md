## 4. Response categorisation

When a reply arrives, classify it as one of:

1. **Access granted** — with terms, file list, data dictionary, or custodian contact.
2. **Partial access** — some datasets/metadata available, others not.
3. **Metadata only** — helpful documentation but no data access.
4. **Redirect** — to another custodian or programme.
5. **Declined** — no access for this use.
6. **No reply** — no response after a reasonable period.

Record the exact date and content summary. Do not infer access from a supportive reply without explicit terms.
